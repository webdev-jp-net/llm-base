# LESSONS.md — 失敗の記録と回避策（エラー分類台帳）

> 「失敗を資産にする」ための台帳。エラーや手戻りが発生したら必ず1行追加する。
> セッション開始時とタスク着手前に、関連カテゴリの教訓を確認して事前回避する。
> 運用ルールは `_llm-rules/self_improvement.md` を参照。

## エラー分類（taxonomy）

| 分類           | 意味                                                         |
| -------------- | ------------------------------------------------------------ |
| hallucination  | 存在しない情報・仕様の生成（仕様書にない機能を勝手に補完等） |
| format_error   | 指定形式・命名規則・ディレクトリ規約への不準拠               |
| context_drift  | 当初の目標・Issueの意図からの逸脱                            |
| tool_failure   | 外部ツール（gh, Codex CLI等）の呼び出し失敗                  |
| spec_gap       | 仕様の空白を確認せず一般論で補完した                         |
| duplicate_impl | 既存実装を確認せず重複実装した                               |
| env_issue      | 環境・依存関係・認証まわりの問題                             |
| process_skip   | ルールファイルの手順を最後まで踏まずに実装へ進んだ           |
